# The plugins that don't ship with Moodle, each in a pinned release: the one made for the image's
# Moodle series. docker/install-plugins.sh installs them when the image is built. They are a real
# Moodle 4.5 campus's (falkenslab/moodle-sandbox#4), to test programs against a Moodle like the
# real ones.
#
# One line per plugin and series: <series> <component> zip <url> <md5>
#                              or <series> <component> git <repository> <tag or commit>
# The series is the start of Moodle's version: "4.5" matches 4.5.x, "5" any 5.x and "*" all of
# them. A plugin without a line for the image's series isn't installed in it.
#
# The zips are those of Moodle's plugins directory (https://moodle.org/plugins), with the md5 it
# publishes; git, the ones that aren't in it.
